This project is a simple JavaScript application to manage a library of books. Users can add, display, remove, and update the read status of books. Each book is represented as an object and stored in an array, allowing the application to dynamically render the library based on the data.

## Getting Started

1. Clone the repository: git clone <repository-url>
2. Open index.html in a browser
3. Use the "New Book"button to add books and interact with library
